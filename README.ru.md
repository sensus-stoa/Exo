# ExoCortex — Персональная Операционная Система

> 🇬🇧 [English version](README.md)

Персональная система анализа дневниковых отчётов через AI-агента. Дневник → транскрибация → AI-анализ по шаблону → гипотезы → задачи на завтра.

500+ гипотез за 3.5 месяца. 30 подтвердились. Большинство я не хотел знать.

## Что внутри

| Файл | Назначение |
|------|-----------|
| `AGENTS.md` | Системный промпт для AI — философия, протоколы мышления, анти-лесть |
| `PIPELINE.md` | Контуры обработки (C1-C4) и правила взаимодействия AI с дневником |
| `DailyLogTemplate.md` | Шаблон ежедневного отчёта v8.4 |
| `examples/daily_report.md` | Демо-отчёт (вымышленный) |
| `examples/metrics.jsonl` | Формат хранения метрик |
| `core/` | Скелет системы: цели, паттерны, гипотезы, калибровка, слепые пятна |
| `attractors/` | Концепция поведенческих аттракторов |

## Быстрый старт

1. Скопируй `DailyLogTemplate.md` — это твой шаблон
2. Скопируй `AGENTS.md` — это инструкция для AI
3. Вечером диктуй отчёт голосом (15-20 мин)
4. Скармливай AI (DeepSeek, Claude, локально — любой)
5. AI заполняет шаблон, пишет гипотезы, ставит задачи

## Что нужно

- Python 3.10+ (для транскрибации)
- GigaAM или Whisper (транскрибация голоса)
- DeepSeek API / Claude API / локальная LLM (анализ)

## Как работает

```
Голос (m4a) → GigaAM/Whisper (локальный STT) → сырой .md
→ AI читает AGENTS.md + шаблон
→ заполняет метрики, ищет паттерны, пишет гипотезы
→ ставит задачи на завтра
→ коммитит в git
```

**Ежедневно:** сигналы, метрики, петля обратной связи по директивам  
**Еженедельно:** дистилляция гипотез, аудит слепых пятен, скорость целей  
**Ежемесячно:** кросс-доменные корреляции, отклонение траектории  
**Ежеквартально:** стратегический deep dive, векторы развития

## Зачем

Большинство AI-приложений для заметок хранят твои мысли. ExoCortex их **анализирует**. Он находит паттерны, которые ты не видишь, потому что находишься внутри них. Это не second brain — это внешний неокортекс.

Без лести. Системный промпт явно запрещает хвалить и требует предельной честности. AI настроен не соглашаться с тобой по умолчанию.
